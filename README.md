# Student Needs Portal

A working static website for the Student Needs Portal project. It helps students discover verified hostels/flats, mess services, and private libraries from one centralized interface.

## Features

- Responsive landing page with project introduction and objectives.
- Student authentication form demo.
- Filterable listings for accommodation, mess services, and private libraries.
- Provider registration demo for admin verification.
- Student feedback form with live review rendering.
- Admin panel preview metrics.

## Run locally

Open `index.html` in a browser, or serve the directory with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
